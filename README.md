# 학과별 쿠폰 현황 대시보드 — 구조와 배포

## 구조

```
Google 설문 ──(응답 제출 트리거)──▶ 설문 Apps Script
                                    ├─ 학과별 인원 집계
                                    ├─ 선택지 비율 갱신 · 10% 채운 학과 제거
                                    ├─ 설문 안 참여 현황 그래프 이미지 다시 그리기
                                    └─ /exec 웹앱: 집계 JSON (학과명 · 인원 · 쿠폰 수만)
                                                   │
GitHub Pages 대시보드 (index.html) ◀── 1분마다 fetch ┘
```

| 파일 | 역할 |
|---|---|
| `index.html` | GitHub Pages에 올라가는 대시보드 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서빙하도록 하는 빈 파일 |
| `apps-script/Code.gs` | 설문에 붙은 Apps Script 프로젝트에 넣을 코드 (GitHub에는 참고용) |

## 현재 상태 (2026-11-05)

- 설문에 붙은 Apps Script에 `apps-script/Code.gs`를 넣었고, setup 실행(응답 트리거 설치)과 웹앱 배포까지 마쳤습니다.
- 재학생 수: IR 학적현황 월별 자료의 2026-10-01 기준 재학생 수를 썼습니다. 25개 학과 합계 5,379명, 쿠폰 548개입니다. 글로벌자유전공학부는 설문 대상에서 제외했습니다.

## 표시 규칙

| 남은 쿠폰 | 표시 |
|---|---|
| 20% 초과 | ✅ 쿠폰 여유 있음 (숫자 숨김) |
| 20% 이하 | ⚠️ 남은 쿠폰 N개! |
| 0개 | — 쿠폰 마감 (맨 아래) |
| 11/15 23:59 이후 | 설문 종료, 바로가기 비활성화 |

쿠폰 수 = 재학생 수 × 10%, 올림

## 배포 순서

1. **재학생 수 입력:** `apps-script/Code.gs`의 `ENROLLMENT`에 26개 학과 재학생 수를 채웁니다.
2. **설문 스크립트에 붙여넣기:** 설문지 → ⋮ → Apps Script로 엽니다. 기존 내용을 지우고 `Code.gs`를 붙여넣은 뒤 저장합니다.
3. **setup 실행:** 함수 목록에서 `setup`을 고르고 실행한 뒤 권한을 허용합니다. 응답 트리거가 설치되고 첫 집계가 돌아갑니다.
4. **웹앱 배포:** 배포 → 새 배포 → 웹 앱을 고르고, 실행은 **나**, 액세스는 **모든 사용자**로 설정합니다. 나오는 `/exec` 주소를 복사합니다.
5. **대시보드 연결:** `index.html`의 `const API_URL = '';`에 `/exec` 주소를 넣습니다.
6. **GitHub Pages:** 이 폴더를 저장소에 올리고 Settings → Pages에서 브랜치 `main` / 폴더 `/ (root)`를 지정합니다.
   주소는 `https://<계정>.github.io/<저장소>/`가 됩니다.

## 주의

- Code.gs를 고친 뒤에는 **배포 관리 → 기존 배포 편집 → 새 버전**으로 다시 배포해야 /exec에 반영됩니다.
- 응답이 거의 동시에 몰리면 목표보다 1~2명 더 받을 수 있습니다. 선택지를 갱신하기 전에 이미 화면을 열어 둔 학생이 있기 때문입니다.

- 응답을 삭제하면 자동 갱신이 일어나지 않습니다. 삭제한 뒤 Apps Script에서 `refresh`를 한 번 실행하면 집계, 선택지, 그래프가 함께 맞춰집니다.
- 소유자 쪽에 응답 제출 때 그래프를 그리는 다른 스크립트가 있으면 이 그래프를 덮어씁니다. 그 스크립트는 꺼 두어야 합니다.
